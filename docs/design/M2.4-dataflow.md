# M2.4 — F5 JSON 编辑器 数据流

> 版本：M2.4 — F5 JSON 编辑器
> 状态：设计完成（实现跟随本文件）

## 业务定义（F5）

用户选择一个 `.json` 文件（如 `~/.claude/settings.json` 或 `~/.claude/providers/*.json`）→ 应用内打开 JSON 编辑器 → 实时编辑 → 保存到原文件。

### 功能要求

1. **文件读写**：通过 Tauri command 读取 + 原子写入（复用 `infrastructure::fs_atomic::write_with_backup`，CLAUDE.md §7）。
2. **语法高亮**：`<textarea>` + CSS 背景色提示（M1.9 已知：避免引入 React 组件库，省 bundle size）。
3. **实时校验**：编辑时 debounce 200ms → `JSON.parse` → 失败显示红色边框 + 错误位置。
4. **格式化**：Ctrl+Shift+F 触发 `JSON.stringify(parsed, null, 2)`。
5. **Token 遮罩**：`api_key` / `token` / `password` / `secret` 等字段显示为 `***MASKED***`，防止截图泄漏。
6. **撤销/重做**：在 `history: string[]` 栈中维护编辑快照，Ctrl+Z / Ctrl+Y 切换。
7. **保存**：先 validate → 二次确认（若失败）→ 调 `write_file_atomic` command。
8. **安全约束**：`write_file_atomic` 必须 `starts_with(~/.claude/)`，否则拒绝。

## 数据流

```
User click sidebar "JSON 编辑器" → setView('json-editor')
  → JsonEditorPage mount
  → 顶部 toolbar 显示：选择文件 / 保存 / 格式化 / 撤销 / 重做 / 遮罩 toggle
  → 用户点击"选择文件" → tauri-plugin-dialog 打开原生 picker
  → 选完 .json → invoke('read_file', { path })
  → 拿到 content → 显示在 textarea
  → 同时: parse JSON → 若成功 → 标记 valid；若失败 → 显示 parse 错误
  → 若 遮罩 toggle ON → 调用 maskTokens(content) → 替换 textarea 显示
  → 用户编辑 → debounced (200ms) validateJson → 更新 error state
  → Ctrl+Z → history.pop() 还原前一个快照
  → Ctrl+Shift+F → formatJson(content) → 替换 textarea + history.push()
  → 点保存 → validateJson → 若无效 → 弹 confirm("JSON 无效，仍要保存吗？")
                → 调 invoke('write_file_atomic', { path, content })
                → toast "已保存" 或 "错误：<msg>"
  → 出错：保留原 content + 显示红色 InfoBar
```

## 设计原则

- **纯函数优先**：mask / validate / format 都是纯函数，单元测试覆盖容易
- **复用 fs_atomic**：M1.x 已实现 atomic write + backup，F5 不重新发明
- **不做过度抽象**：单页实现，不到 300 行；不用 form 库 / monaco editor（M1.9 已记录 bundle size 考量）
- **安全第一**：写入路径必须 starts_with(`~/.claude/`)
- **零 token 泄漏**：遮罩 toggle 默认 ON；modal 显示字段名，绝不显示 api_key 值
