**禁止**：
- 业务代码直接调 `std::fs` —— 走 `infrastructure::fs_atomic`
- 业务代码直接拼 `~/.claude/...` 路径 —— 走 `IPlatformPaths`（CLAUDE.md §3.2）
- 后端把 `windows-specific` 路径逻辑硬编码 —— 走 `WindowsPaths::resolve()`
- 把 `~/.claude/settings.json` 反序列化成强类型后再回写 —— 丢失未知字段（SPEC §6.1）。**改用 `serde_json::Value` / `Map<String, Value>` 修改子键**。

## 2. 数据模型（SPEC §2.1）

### 2.1 Provider（本地库条目）

每个 provider 一个独立 JSON 文件，路径 `<app-data>/providers/<id>.json`。
（M2.3+ 会改成一个集中的 `providers.json`；M2.1 沿用文件粒度便于回滚 + 增量同步。）

```rust
// src-tauri/src/domain/provider.rs
pub struct Provider {
    pub id: String,             // kebab-case, 库内唯一
    pub name: String,           // "GLM-4.6 官方"
    pub provider_type: String,  // "anthropic" / "openai" / "deepseek"
    pub api_base: String,       // ANTHROPIC_BASE_URL
    pub api_key: String,        // ANTHROPIC_AUTH_TOKEN
    pub models: Vec<String>,    // 模型列表（M2.1 渲染,F7/F18 后面用）
    pub is_active: bool,        // 当前是否激活（冗余字段,真相是 settings.json）
    pub created_at: i64,        // unix seconds
    pub last_used_at: Option<i64>,
    pub notes: Option<String>,
}
```

**is_active 真相来源**：每次 `list_providers()` 时重新从 `~/.claude/settings.json` 的 `env.ANTHROPIC_BASE_URL` + `env.ANTHROPIC_AUTH_TOKEN` 匹配计算，**不信任库文件里的标记**（SPEC §2.3）。

### 2.2 settings.json 结构（Claude Code 真实格式，平台定义）

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.anthropic.com",
    "ANTHROPIC_AUTH_TOKEN": "sk-ant-...",
    "ANTHROPIC_MODEL": "claude-sonnet-4-6"
  },
  "enabledPlugins": { ... },
  "hooks": { ... },
  "permissions": { ... }
}
```

**M2.1 切换**：只动 `env.ANTHROPIC_BASE_URL` + `env.ANTHROPIC_AUTH_TOKEN` + `env.ANTHROPIC_MODEL`（如 provider.models 非空）。其他字段原样保留。

## 3. F1 数据流

```
[用户] click "Provider 列表" → App.tsx router setView('provider-list')
  ↓
[App.tsx] switch on view: provider-list → <ProviderListPage />
  ↓
[ProviderListPage mount]
  - useEffect → invoke('list_providers')
  - 显示 loading
  ↓
[Tauri IPC] list_providers 命令
  ↓
[ProviderService.list_providers()]
  1. paths.resolve() → AppPaths (via IPlatformPaths, 不直接拼)
  2. 读 ~/.claude/providers/*.json → Vec<Provider>
     - 目录不存在 → 返回空 Vec（不报错,M2.1 冷启动正常）
     - 单个文件 JSON 损坏 → 跳过 + log 警告(不要破坏整个列表)
  3. 读 ~/.claude/settings.json → 提取 env.ANTHROPIC_BASE_URL + ANTHROPIC_AUTH_TOKEN
     - 文件不存在 → 没有激活 provider,所有 is_active = false
     - JSON 损坏 → 同上 + log 警告
  4. 匹配: provider.is_active = (base_url + api_key 全等)
  5. 返回 Vec<Provider>
  ↓
[ProviderListPage] setProviders(list)
  ↓
[UI] 渲染表格: name | type | api_base | [激活] 按钮 / [● 已激活] 徽章
```

**错误处理**（SPEC §6.5）：
- `~/.claude/providers/` 不存在 → 表格 + 空状态"还没有任何 provider"
- 单个 provider 文件坏 → 跳过 + 红色 InfoBar "1 个 provider 配置损坏已跳过"
- settings.json 读不出 → 所有 is_active = false + InfoBar "无法读取当前 Claude 配置"

## 4. F2 数据流

```
[用户] click 行内 [激活] 按钮 → onActivate(provider.id)
  ↓
[ProviderListPage]
  1. setSwitching(true) → 按钮 disabled + 显示 spinner
  2. invoke('switch_provider', { providerId })
  3. 成功 → setProviders(await listProviders()) → 徽章更新 + InfoBar "已切换到 X"
  4. 失败 → 红色 InfoBar "切换失败: <错误>" + 按钮恢复
  ↓
[Tauri IPC] switch_provider 命令
  ↓
[ProviderService.switch_provider(id)]
  1. 找 provider(从 <app-data>/providers/<id>.json 读)
     - 找不到 → 返回 Err(ProviderNotFound)
  2. 读 ~/.claude/settings.json
     - 不存在 → 用空 {env:{}} 起
     - 损坏 → 返回 Err(SettingsCorrupted)
  3. write_with_backup(settings.json, modified_settings_json)
     - 先 copy 到 settings.json.bak.<ts>
     - 写 settings.json.tmp.<uuid>
     - atomic rename 到 settings.json
     - 任一步失败 → 返回 Err 但 .bak 保留供用户手动回滚（SPEC §6.2）
  4. 更新 provider 库:写回 <app-data>/providers/<id>.json (is_active=true, last_used_at=now)
  5. 返回 Ok(())
```

**原子性保证**（SPEC §6.1 + CLAUDE.md §7）：
- 备份名格式 `settings.json.bak.yyyyMMdd-HHmmss`（永远不重名）
- 临时文件名 `<original>.tmp.<uuid>`（不污染备份命名空间）
- `rename()` 在 Windows 上 = `MoveFileEx(..., MOVEFILE_REPLACE_EXISTING)`，POSIX 上是原子覆盖
- 任一步失败 → settings.json 不动,bak 文件保留,UI 给用户可读错误

## 5. 接口签名（前后端契约）

### 5.1 Rust command

```rust
#[tauri::command]
pub async fn list_providers(
    paths: State<'_, Arc<dyn IPlatformPaths>>,  // 注入 platform paths
) -> Result<Vec<Provider>, String>;

#[tauri::command]
pub async fn switch_provider(
    paths: State<'_, Arc<dyn IPlatformPaths>>,
    provider_id: String,
) -> Result<bool, String>;
```

错误用 `String` 序列化到前端（Tauri 要求 `Serialize`，最简类型）。

### 5.2 TypeScript mirror

```typescript
// src/types/provider.ts
export interface Provider {
  id: string;
  name: string;
  provider_type: string;
  api_base: string;
  api_key: string;        // M2.5+ 加遮罩; M2.1 原样
  models: string[];
  is_active: boolean;
  created_at: number;
  last_used_at: number | null;
  notes: string | null;
}

export const listProviders = (): Promise<Provider[]> =>
  invoke<Provider[]>('list_providers');

export const switchProvider = (providerId: string): Promise<boolean> =>
  invoke<boolean>('switch_provider', { providerId });
```

**字段命名约定**：Rust 用 snake_case + `#[serde(rename_all = "snake_case")]` → 前端 camelCase `provider_type` 而不是 `providerType`，保持和 SPEC §2.1 数据表一致。

### 6.2 状态

| 状态 | 表现 |
|---|---|
| loading | 表格区显示 "加载中…" + ProgressRing |
| error | 红色 InfoBar 横置顶部 "错误: <msg>" |
| empty | 大图标 + "还没有任何 provider" + "从当前 settings.json 导入" 提示（M2.3+ 实现） |
| 切换中 | 该行按钮 disabled + spinner "切换中" |
| 切换成功 | 顶部绿色 InfoBar 3 秒 "已切换到 <name>" |
| 切换失败 | 顶部红色 InfoBar 5 秒 "切换失败: <msg>" |

- 颜色：`--accent` (激活条)、`--success` (已激活徽章)、`--danger` (错误)
- 间距：`--space-4/6/8` (16/24/32px)
- 圆角：`--radius-card` (8px)
