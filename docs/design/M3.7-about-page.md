## §1 背景

清单 18 (P1):"单文件部署 — 干啥的看不懂,'当前应用'区域抽出来做'关于'页"。

触发原因:

- (c) sidebar 路由加 "关于" 入口

## §3 重构设计

### 3.1 F8 单文件部署页面文案重写

**目标**:从"6 字段 metadata + 3 条命令" → "1 段功能解释 + 3 条 installer 命令"。

文案策略:
- 标题保留"单文件部署"
- Intro 从"应用 = 一个可执行文件..."改为:
  > 把应用打包成单个可执行文件(.exe / .dmg),无需用户安装 .NET / Node / Python runtime。
  > 应用自包含 WebView2(Windows)或 WKWebView(macOS)渲染引擎。
  > 下方展示如何在本地触发 installer 构建 + 校验产物完整性。
- 删除"当前应用" metadata 卡片(M3.7 迁移到 about 页)
- 保留"查看 installer 生成命令" toggle + 3 条命令(Windows NSIS / macOS DMG / SHA256)
- toggle 文案从"查看 installer 生成命令"改为"查看构建命令"

**保留 F8 功能**:`get_app_metadata` IPC 调用保留(给 about 页复用),不破坏向后兼容。

### 3.3 组件拆分

新建 2 个共享组件(放 `src/components/`,便于其他页复用):

- **`AboutCard.tsx`**:通用卡片容器(border + radius + bg-elevated + padding)
- **`InfoSection.tsx`**:关于页分区(标题 + key-value 列表,支持 mono 字体)

设计原则:
- 不引入新 Tailwind 类(项目无 Tailwind 管线,见 CLAUDE.md §2.4)
- 全部样式 inline `style={{}}`,沿用 single-file-deploy 已有模式
- 复用现有 CSS tokens(`--bg-elevated` / `--border` / `--text-primary` / `--font-mono`)

### 3.4 sidebar 路由加"关于"入口

- **`useViewState.ts`**: `ViewId` union 加 `'about'`,`ALL_VIEWS` 末尾追加(13 → 14 项)
- **`AppSidebar.tsx`**: `VIEW_META` 加 `about: { icon: <Info />, short: '关于' }`
- **`App.tsx`**: `PAGE_META` 加 `about: { title: '关于', description: '...' }`,view === 'about' 分支渲染 `<AboutPage />`

**不动 D-槽1 sidebar 顶部 project switcher**:about 入口作为底部新按钮加,不是替换顶部。

### 3.5 LICENSE 内容引用方式

**embedded string**(不读 LICENSE 文件):
- 项目根目录无 LICENSE 文件(`ls LICENSE` 确认 missing)
- M3 阶段占位:MIT(符合 CLAUDE.md §1 "跨平台桌面工具" 开源定位)
- 许可证内容硬编码到 InfoSection props(简单字符串,不需要文件 IO)
- M4 公证阶段会补 LICENSE 文件 + 真实仓库链接,届时改为 `fetch('/LICENSE')`
