# M2.13 — F16 资源浏览数据流

## 目标

让用户在 Claude 配置管理器里**一眼看清**当前启用的所有 Claude Code 资源（Plugins / Skills / Commands / LSP / MCP）,并提供**一键 reveal** 跳到文件管理器定位具体文件。

F16 是 sidebar 12 个 plugin 中最后一个仍为 placeholder 的核心模块；F18 backup-restore + F18 optimizer 已经在 M2.6 / M2.9 ship。

## 数据流

```
[F16 数据流]

User click "资源浏览" sidebar tile
  → setView('resource-browser')
  → ResourceBrowserPage mount
  → useEffect: invoke('list_resources', { kind: 'plugins' })
       ↓
       Tauri command: commands::resource::list_resources
       ↓
       ResourceService::list(kind)
         1. 解析 <claude_dir>/{plugins,skills,commands,lsp}/ (走 IPlatformPaths)
         2. 按 kind 调 infrastructure::resource_scanner::scan_resources
         3. 对于 Mcp kind:复用 McpService 解析 ~/.claude/mcp.json
         4. 返回 Vec<ResourceItem> { id, name, kind, path, size_bytes, enabled }
       ↓
  ← Vec<ResourceItem>
  → UI 渲染该 kind 的列表（name + size + enabled badge + reveal 按钮）

User switch tab
  → setKind('skills') → 重 invoke('list_resources', { kind: 'skills' })

User click [在文件管理器中显示]
  → invoke('reveal_in_file_manager', { path })
       ↓
       Tauri command: commands::resource::reveal_in_file_manager
       ↓
       ResourceService::reveal(path)
         1. 走 IPlatformReveal trait
         2. Windows: explorer /select,<path>
         3. macOS: open -R <path>
       ↓
  ← Ok(()) 或 Err(String)
  → UI 成功 → toast "已打开"
  → UI 失败 → 模态 "无法打开: <reason>"（不阻塞 UI,不退出）
```

## 5 类资源来源

| kind | 目录 | 内容形式 | `enabled` 来源 |
|---|---|---|---|
| `plugin` | `~/.claude/plugins/<name>/` | 目录(每个 plugin 一个子目录) | 恒为 `true`(目录存在即启用;M2.13 不读 enabled.json) |
| `skill` | `~/.claude/skills/<name>/SKILL.md` | 文件或目录 | 恒为 `true`(存在即启用) |
| `command` | `~/.claude/commands/<name>.md` | 单个 `.md` 文件 | 恒为 `true` |
| `lsp` | `~/.claude/lsp/<name>.json` | 单个 `.json` 配置文件 | 恒为 `true` |
| `mcp` | `~/.claude/mcp.json` 内 `mcpServers` keys | JSON key 列表 | 走 McpService:每个 server 的 `disabled: true` 标志 |

## 类型契约

### ResourceItem

```rust
struct ResourceItem {
    id: String,           // "<kind>/<name>" 例如 "plugins/code-review"
    name: String,         // 显示名,不带前缀路径
    kind: ResourceKind,   // Plugin | Skill | Command | Lsp | Mcp
    path: String,         // 完整绝对路径
    size_bytes: u64,      // 文件大小或目录递归总大小(plugin = 目录递归,其它 = 文件)
    enabled: bool,        // 见上表
}

enum ResourceKind { Plugin, Skill, Command, Lsp, Mcp }
```

serde rename_all = "lowercase",前端 tag = `"plugin" | "skill" | "command" | "lsp" | "mcp"`。

## 安全保证

- `reveal_in_file_manager` 走 `IPlatformReveal` trait(CLAUDE.md §3.2):Windows impl 已经做 `path.exists()` 检查;macOS stub 是 unimplemented
- 任何 reveal 失败 → Tauri command 返回 `Err(String)`,前端 modal 显示,**不抛 panic, 不阻塞 UI**
- 路径永远从 `AppPaths` 派生,前端无法注入任意路径
