# M2.7 F7 — 用量查询 数据流

> **迭代**: M2.7
> **功能**: F7 用量查询（5h / 1w / 1m 时间窗 + 余额 + 5 分钟缓存）
> **范围**: M2.7 stub 模式 —— 只读 `~/.claude/usage.json`；外部 API（M2.8+）

---

## 1. 数据源

| 来源 | 用途 | M2.7 状态 |
|------|------|----------|
| `~/.claude/usage.json` | Claude Code 自身写的本地用量快照 | **已实现**（stub 模式） |
| Anthropic 用量 API（`api.anthropic.com/v1/usage`） | 实时 5h 配额 | M2.8+ |
| OpenAI billing API | 按需 | M2.8+ |
| 第三方 provider（DeepSeek / GLM 等）的等价端点 | 按需 | M2.8+ |

> **M2.7 设计原则**: 永远不假装我们能调外部 API —— `usage.json` 缺数据时返回
> `UsageSnapshot::empty`（tokens = 0, cost = None），UI 显示"暂无数据"。

---

## 2. 数据流

```
[F7 数据流]
User click "用量查询" → setView('usage-query')
  → UsageQueryPage mount
  → invoke('get_current_usage', { window: '5h' | '1w' | '1m' })
  → Rust：
    1. 读 ~/.claude/settings.json → 找 active provider（用 ANTHROPIC_BASE_URL + TOKEN hash 作为 fingerprint）
    2. 查 in-memory cache（5min TTL），key = (provider_fingerprint, window)
    3. cache miss → 读 ~/.claude/usage.json（本地 Claude Code 写的）
    4. 返回 UsageSnapshot { provider_id, window, tokens_used, cost_usd, balance_usd, timestamp }
  → UI 渲染数字 + sparkline 趋势

点 "刷新" → invoke('refresh_usage') → 清 cache + 重 invoke

切时间窗 → 重新 invoke（cache 可能 miss if different window）

切换 provider → 新的 fingerprint → 新的 cache key → 自然 miss → 重读 usage.json
```

---

## 3. on-disk 形状（usage.json）

Claude Code 的 native 格式（M2.7 假设）：

```json
{
  "providers": {
    "<provider_id>": {
      "5h":  { "tokens_used": 12345, "cost_usd": 0.12 },
      "1w":  { "tokens_used": 67890, "cost_usd": 1.23 },
      "1m":  { "tokens_used": 234567, "cost_usd": 4.56, "balance_usd": 99.44 }
    }
  }
}
```

缺失字段容错：
- 整个文件缺失 → 返回 `empty(provider_id, window)`
- `providers.<id>` 缺失 → 返回 `empty(...)`
- `<id>.<window>` 缺失 → 返回 `empty(...)`
- 单个字段缺失（`cost_usd` / `balance_usd`）→ `None`

任何错误都不是 IPC 错误 —— UI 仍能渲染零值。

## 4. 缓存策略

| 维度 | 取值 |
|------|------|
| Cache 类型 | `HashMap<String, CacheEntry>` in `Mutex` |
| Key | `(provider_fingerprint, window)` — fingerprint 切换 provider 自动 miss |
| TTL | **5 分钟**（CLAUDE.md §3.3 F7 要求） |
| 失效 | `refresh_usage` 命令强制清除 + 重读 |
| Provider 切换 | 新的 fingerprint → 新的 key → 自然 miss |

> **测试考虑**: `UsageService::with_ttl` 接受自定义 TTL，单元测试用 1 秒 TTL 验证
> "expired → reread" 分支而无需 sleep 5 分钟。

## 6. IPC contract

### `get_current_usage(window: String) → UsageSnapshot`

- **入参**: `window` 严格匹配 `"5h"` / `"1w"` / `"1m"`（其他值 → `Err("未知的窗口: '...', 请用 5h / 1w / 1m")`）
- **返回**: `UsageSnapshot`（snake_case fields）
- **错误**: 仅当 AppPaths 解析失败 或 usage.json 是 corrupt JSON（非 missing）时返回错误

### `refresh_usage(window: String) → UsageSnapshot`

- 同上，但先清 cache 再读

---

## 7. 已知限制（M2.7 范围内）

- 仅本地 stub —— 不发外部 HTTP 请求
- provider fingerprint 用 `ANTHROPIC_BASE_URL + ANTHROPIC_AUTH_TOKEN` 的 hash，
  不是真正的 provider.id（不影响功能，但 UI 标签会显示 `active-<hex>`）
- 无历史趋势 —— "最近 24 次" 留到 M2.8+（需要持久化 history）
- 无 sparkline 数据源 —— M2.7 用一个占位 sparkline（恒定值），M2.8+ 接历史
- 切时间窗不清 cache —— 不同 window 有独立 cache entry，互不影响
