### 4.3 三大痛点(§3) — 对比表
| 现状(手动) | 用 Claude Config Manager |
|---|---|
| 手编 `~/.claude/settings.json` 切换 provider(2-5 分钟,易错) | 双击卡片,1 秒切换,自动备份原文件 |
| 复制 `ANTHROPIC_AUTH_TOKEN` 字段容易漏空格 | 表单 + 校验 + token-mask 防肩窥 |
| MCP 启用列表手改,容易破坏其他键 | 一行 toggle,只动 `mcpServers` 字段,其他键保留 |
| 用量超额才发现被限额 | provider 卡片常驻用量徽章,详情页看精确数字 |
| 想看当前生效的 env/hooks,只能 cat settings.json | 可视化 JSON 编辑器,带语法高亮 + 校验 + 格式化 |

## 5. 生成脚本设计

**文件**:`D:/project/winui3/scripts/gen-intro-docx.py`

**依赖**:`python-docx`(若未装,脚本头部自动 pip install)

**关键函数**:
- `add_title(doc, text, level)`:添加标题(Heading 1/2)
- `add_paragraph(doc, text, style='normal')`:添加段落
- `add_ascii_block(doc, text)`:用 Consolas 9pt + 浅灰底 + 1.0 行距 渲染 ASCII 框图
- `add_table(doc, headers, rows)`:添加对比表
- `add_page_break(doc)`:分页
- `set_footer(doc, version)`:页脚含版本 + 页码

**章节编排顺序**:
1. 封面(分页)
2. 一句话定位(分页)
3. 三大痛点
4. 核心功能(5 个 ASCII 框图,每个独立段落 + 简短解释)
5. 技术亮点(分页)
6. 当前进度(分页)

## 7. 风险与约束

| 风险 | 缓解 |
|---|---|
| `python-docx` 未安装 | 脚本自动 pip install |
| Windows 上字体名差异 | 显式指定中文字体名("宋体")而非 "SimSun" |
| 桌面权限 | 脚本在用户主目录下生成,无 UAC |
| ASCII 框图字符宽度 | 用等宽字体 Consolas + 1.0 行距 + 浅灰底色,确保对齐 |
| 后续修改 | 脚本和数据分离,改章节文字后重跑脚本即可 |
