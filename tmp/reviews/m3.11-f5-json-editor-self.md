## 核心实现 diff
```rust
// 新增 scope root 计算(改动前无此概念)
let (scope_root, join_root) = match active_root {
    Some(root) => (root.join(".claude"), root.to_path_buf()),
    None => (
        paths.claude_dir()
            .map(|p| p.to_path_buf())
            .unwrap_or_else(|| paths.home.join(".claude")),
        paths.home.clone(),
    ),
};
```

改动后所有 `state.paths.home.join(".claude")` 替换为 `scope_root`,所有相对路径
join 改为 `join_root.join(...)`(项目模式下 join 到 project root 而非 user home)。

## 调用方改动
两个调用点 (`read_file` line 55-68, `write_file_atomic` line 79-93) 都加了:
```rust
let active_root = crate::platform::runtime::paths().active_root_dir();
let resolved = resolve_claude_path(&state.paths, active_root.as_deref(), &path)?;
```

注释明确: active_root 是"live" 状态(state.paths 是 startup snapshot,
active_root 可以 runtime 切换)。
