### §2.2 错误处理

- `install_builtin` 找不到 `claude` CLI → `MarketplaceError::Git` 含可读消息("请确认 Claude Code 已安装")
- `install_npx` 找不到 `npx` → `MarketplaceError::Git` 含可读消息("请确认 Node.js + npm 已安装")
- `install_third_party` 某个 selection 不存在 → 错误传播, 不静默吞错 (CLAUDE.md §7)
- MCP 安装 → 沿用现有 `installed: false` + message (清单 11)
- resource_scanner 过滤污染目录 → 跳过 (不报错, 静默过滤 = 设计意图)

### §2.3 UI 一致性

## §4 风险评估

**低风险**:
- InstallMode serde 兼容性 (Default derive 兼容老 JSON)
- 前端 InstallMode 类型 ('builtin' | 'npx' | 'git') 镜像后端 enum
- EXCLUDED_DIR_NAMES 是字符串列表, 易扩展

**中风险**:
- 真机 install_builtin 链路需要 Claude Code CLI 装好才能跑通 — e2e 验证需 Mac/Win 真机 (D6 暂缓)
- 真机 install_npx 需要 npm registry 可达 + 包存在 — e2e 验证需网络通

**零阻塞**:
- 编译 (本 subagent 文件全部通过)
- 现有测试 (无破坏性改动)
- API wire format (serde default 兼容老调用方)
