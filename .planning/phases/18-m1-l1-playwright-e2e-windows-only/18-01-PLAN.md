## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dev box → tauri-driver | Localhost only; tauri-driver is the WebDriver intermediary (default port 4444) |
| tauri-driver → release exe | Spawned fresh per WebDriver session via `tauri:options.application` payload |
| release exe → WebView2 | Single-instance constraint; WebView2 exposes CDP `debuggerAddress` (ephemeral port) |
| WebView2 → Playwright (via CDP) | connectOverCDP reads `CDP_ENDPOINT` env var; no auth required (local-only) |
| subagent → run-e2e.sh | Orchestration script handles cleanup via `kill-app.sh` trap; stale `tauri-driver` / `msedgedriver` processes forcibly killed in pre-cleanup |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-18-02 | Information Disclosure | CDP `debuggerAddress` exposed on localhost without auth | accept | Localhost-only binding; no remote access; dev-box session scope only |
