# Plan 03: BZ-07 CliNotFound 4-category error localization

## Scope

Replace single-variant `MarketplaceError::CliNotFound { cmd: String }` with 4 category-specific variants (启动 / git / install / scan), each with zh-CN `Display` impl. Update spawn sites and UI to surface categorized error.

## Background

Current state (verified):
- `src-tauri/src/services/marketplace_service.rs:165-189` defines `MarketplaceError` enum with one `CliNotFound { cmd: String }` variant
- `src-tauri/src/services/marketplace_service.rs:540-545` `claude` CLI spawn failure → `CliNotFound { cmd: "claude" }`
- `src-tauri/src/services/marketplace_service.rs:650-655` `npx` CLI spawn failure → `CliNotFound { cmd: "npx" }`
- `src/pages/marketplace/index.tsx:203-212` UI stringifies error and stores in state (no categorization)

The user feedback is: when F17 marketplace fails, ErrorBanner should show a specific localized message ("无法启动 git 命令行工具,请安装 Xcode CLT (macOS) 或 Git for Windows") rather than generic "CliNotFound claude".

### T3.2: Refactor `MarketplaceError` enum
- File: `src-tauri/src/services/marketplace_service.rs:165-189`
- Rename `CliNotFound { cmd: String }` → `StartupCliMissing { cmd: String }` with zh-CN Display:
  ```rust
  #[error("启动失败: 未找到 {cmd} CLI。请确认已安装并加入 PATH(macOS 需 Xcode CLT 或对应包管理器,Windows 需安装 Git for Windows)")]
  StartupCliMissing { cmd: String },
  ```
- Add new variants:
  ```rust
  /// git 操作失败 (网络/认证/无效 URL)
  #[error("git 操作失败: {0}")]
  GitFailed(String),

  /// 安装阶段失败 (CLI 在 PATH 但 install 子命令 exit != 0)
  #[error("安装失败: {cmd} {stage} 阶段异常 — {detail}")]
  InstallFailed { cmd: String, stage: String, detail: String },

  /// 扫描阶段失败 (clone 成功但扫描 5 kind 失败)
  #[error("扫描失败: {0}")]
  ScanFailed(String),
  ```
- Keep `Git(String)` as deprecated alias or remove it (lean: remove and migrate callers)
