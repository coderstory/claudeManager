### B3. M1 遗留设计限制

> 来源：`docs/milestones/M1-final-report.md §5`（8 条风险，本节摘 2 条仍未彻底关闭的）

#### #9 dark theme — 状态变更：已解决（非死代码候选，已彻底清理）

**旧清单（M1-final-report §5.1）**：`[data-theme="dark"]` block 覆盖了 `--bg-primary` / `--bg-elevated` / `--text-*` / `--border` / `--accent` / glass tokens，但**没覆盖** `--success` / `--warning` / `--danger` / `--shadow-sm` / `--shadow-md` / `--disabled` 共 6 个变量。当时记为"待修缺陷，5 分钟修"。

**实际状态（2026-06-22 核实）**：M2.16 theme-trim 已彻底处理，**不再是缺陷，也不是死代码候选**：

1. **dark block CSS 已删除** — `src/design-system/tokens.css:130-134` 注释明确："砍到单档 light (瓷白 #FAFAF7)。原 glass-clear / glass-tinted 两档因 Win11 Mica 不生效(3 档视觉无区别)已移除"。`[data-theme="dark"]` 选择器已不存在于 tokens.css。
2. **ThemeProvider 拒绝 dark/auto** — `src/design-system/ThemeProvider.tsx:45` 注释："'dark' / 'auto' 全部被拒绝,读取时 fallback 到默认 'light'"。localStorage 旧值（`glass-clear` / `glass-tinted` / `dark` / `auto`）读取时 fallback 到 `light`。
3. **主题切换 UI 已移除** — `cycleTheme` 按钮已从 AppHeader 移除。`src/__tests__/integration/App.test.tsx:164` 注释："如后期重新加多档主题,先在此处恢复 cycleTheme + 按钮"。
4. **架构接口保留** — tokens.css 注释："后期再加新主题时在这里加 `[data-theme="xxx"]` 块即可。`:root` 即 light,无需额外 `[data-theme="light"]` 选择器"。

**用户确认（2026-06-22）**：主题切换 UI 已移除，只留单一主题（light 瓷白）。

**结论**：B3#9 dark theme **已解决**。M1 期间"缺 6 个 CSS 变量"的缺陷随着 dark block 整个被删而消失。如未来恢复多档主题，需重新写完整的 `[data-theme="dark"]` block（含 6 个状态/shadow 变量），不是"补 6 个变量"那么简单。
