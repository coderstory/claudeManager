## D-45-A: ServiceRegistry API 形状统一 Arc 路径 ✅

**决策**: `register_arc<T: Send + Sync + 'static>(Arc<T>)` + `get<T>() -> Option<Arc<T>>`

**接口契约 (Phase 42 + Phase 45 共同遵守)**:
```rust
pub struct ServiceRegistry {
    services: RefCell<HashMap<TypeId, Box<dyn Any + Send + Sync>>>,
}

impl ServiceRegistry {
    pub fn new() -> Self;
    pub fn register_arc<T: 'static + Send + Sync>(&self, svc: Arc<T>);
    pub fn get<T: 'static + Send + Sync>(&self) -> Option<Arc<T>>;
}
```

**理由**:
- 9 service 拓扑互注入需要共享所有权(A→B→C→A cycle 必须用 Arc, 借用检查器拒绝 &T)
- 9 次 Arc clone 纳秒级, 性能忽略
- 与 Phase 45 §4 拓扑序 + Phase 45 §6.4 commands 取依赖方式天然对齐

**影响 RESEARCH.md**:
- 42-RESEARCH.md §Pattern 3 ServiceRegistry 骨架 → 改写为 Arc 形态 (而非 `register<T>(T)` 混合)
- 45-RESEARCH.md §2.1 / G1 灰区 → 关闭, 标"已统一 D-45-A"
- 45-RESEARCH.md §2.2 接口契约 → 与 42-RESEARCH §Pattern 3 字节级一致

**影响 PLAN**:
- 42-PLAN.md `plugins/service_registry.rs` 按 D-45-A 接口实现
- 45-PLAN.md 9 service plugin init 用 `ctx.services.register_arc::<HistoryService>(Arc::new(HistoryService::new()))` 模式
- 45-PLAN.md `get_service!` macro 解引用 Arc (例: `&*get_service!(state, HistoryService).unwrap()`)

## D-CC-A: PluginContext 冻结 4 字段 + `&mut` init 签名 ✅

**决策**: PluginContext 最终 4 字段, IPlugin::init 接 `&mut PluginContext`

**最终接口契约**:
```rust
pub struct PluginContext<'a> {
    pub app: &'a AppHandle,
    pub paths: &'a Arc<dyn IPlatformPaths>,
    pub services: &'a mut ServiceRegistry,    // Phase 42 引入
    pub host: &'a PluginHost,                  // Phase 43 引入
}

pub trait IPlugin {
    fn id(&self) -> &'static str;
    fn name(&self) -> &'static str;
    fn routes(&self) -> Vec<PluginRoute>;
    fn services(&self) -> Vec<PluginService>;
    fn commands(&self) -> Vec<CommandSpec>;        // Phase 42 引入
    fn tray_items(&self) -> Vec<PluginTrayItem>;   // Phase 43 引入
    fn app_menu_items(&self) -> Vec<PluginAppMenuItem>;  // Phase 43 引入
    fn depends_on(&self) -> Vec<&'static str>;     // Phase 45 引入
    fn init(&mut self, ctx: &mut PluginContext) -> Result<(), PluginError>;
    fn shutdown(&mut self) -> Result<(), PluginError>;
}
```

**兼容性**:
- 现状 2 字段(app + paths)→ 4 字段, lib.rs:247 调用点必须改
- 现状 `init(&mut self, ctx: &PluginContext)` → `init(&mut self, ctx: &mut PluginContext)`, 10 stub 全部要改 (加 `&mut`)
- 9 stub 重编译不可避免, 但一次性付清, 避免 Phase 45 BC 损失

**影响 RESEARCH.md**:
- 42-RESEARCH.md §Cross-Phase Interface Contracts Phase 43 / 45 段落 → 引用 D-CC-A 冻结的字段集
- 43-RESEARCH.md §Core Plugin Design A7 → 引用 D-CC-A, 不再各自提议字段
- 45-RESEARCH.md §7.3 / G6 灰区 → 关闭, 标"已冻结 D-CC-A"
- 45-RESEARCH.md §8.2 init 顺序 → 按 4 字段 ctx 写伪代码

**影响 PLAN**:
