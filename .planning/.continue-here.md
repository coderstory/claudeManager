> These are not suggestions. Each constraint below was discovered through failure.

- [x] CONSTRAINT: Tauri v2 `cargo build --release` REQUIRES `--features tauri/custom-protocol` — without it, `tauri::generate_context!()` embeds ZERO dist files and runtime webview tries to load dev server (ERR_CONNECTION_REFUSED). Source: tauri-2.x/src/build.rs:256-261, tauri-codegen/src/context.rs:178-184. **Mitigation**: `scripts/build-and-ship.sh` already includes the feature flag. Do NOT remove it. If you re-derive the build command, you MUST add `--features tauri/custom-protocol`.
- [x] CONSTRAINT: Git Bash mangles `/F` in `taskkill /F /IM` as `F:/` (msys path conversion) — script reports success but process stays alive. **Mitigation**: `scripts/kill-app.sh` uses `taskkill -F -IM` (dash, not slash). Same pattern applies to `sc`, `net`, `ipconfig` — use `-flag`.
- [x] CONSTRAINT: Smoke test originally only checked process+window existence — gave false 4/4 PASS even when app rendered blank/stale/ERR_CONNECTION_REFUSED. **Mitigation**: Test 5 (WebView2 child class names like `WRY_WEBVIEW`, `Chrome_WidgetWin_0`), Test 6 (window title matches tauri.conf.json), Test 7 (grep exe for dist JS bundle fingerprint, e.g. `index-XXXX.js`).

## Critical Anti-Patterns (do NOT repeat these)

<!-- Mistakes discovered this session that must be structurally avoided -->

- **ANTI-PATTERN**: Subagent prompt says "fix the build" → subagent runs `cargo build --release` without `--features tauri/custom-protocol` → ships blank page → next session has to debug from scratch. → **MITIGATION**: `scripts/build-and-ship.sh` has the feature flag hardcoded with explanatory comment. NEVER change that line. If re-deriving the build, copy the exact cargo command from build-and-ship.sh.

- **ANTI-PATTERN**: Subagent prompt says "kill the process" → subagent uses `taskkill /F /IM` → Git Bash mangles `/F` as path → process stays alive → next test cycle fails. → **MITIGATION**: `scripts/kill-app.sh` uses `taskkill -F -IM`. NEVER use `/F` in Git Bash. Memory `feedback/taskkill-dash-flags-not-slash.md` documents.

- **ANTI-PATTERN**: Smoke test only checks `Get-Process | count > 0` → passes 4/4 even when app is broken (blank page / ERR_CONNECTION_REFUSED / stale dist). → **MITIGATION**: Tests 5 (WebView2 child class), 6 (window title match), 7 (dist fingerprint in exe) all required. Test 7 is THE regression detector for the `custom-protocol` feature regression.

- **ANTI-PATTERN**: Subagent reports "smoke test passed" without actually running it (e.g. assumes the build is fine, returns success without checking). → **MITIGATION**: All subagent prompts for ship/build tasks MUST include explicit `smoke-test.sh` invocation with 4-digit PASS count requirement. - **ANTI-PATTERN**: Working tree accumulates changes from 4 parallel subagents with no commits — if any subagent fails, context is lost across sessions. → **MITIGATION**: Each subagent task commits atomically before returning.
